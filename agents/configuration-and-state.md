# Configuration and on-disk state

## Environment variables

| Variable | Used by | Meaning |
| --- | --- | --- |
| `DISCORD_TOKEN` | `config.mjs` | Single bot token (account id `default`) |
| `DISCORD_ACCOUNTS_JSON` | `config.mjs` | JSON array or `{accounts:[…]}` of `{id, tokenEnv, priority, expectedGuildIds}`. Takes precedence |
| `DISCORD_ACCOUNTS_FILE` | `config.mjs` | Path to the same JSON document |
| *(each `tokenEnv`)* | `config.mjs` | The actual token for that account. Unexpanded `${VAR}` placeholders are rejected |
| `DISCORD_MAX_IMAGE_BYTES` / `DISCORD_MAX_IMAGES` / `DISCORD_MAX_TOTAL_IMAGE_BYTES` | `config.mjs` | Image limits (default 8 MiB / 4 / 20 MiB; max 25 MiB / 10 / 50 MiB) |
| `DISCORD_ENV_FILE` | plugin `start.mjs` | Credentials file to load (default `$XDG_CONFIG_HOME/discord-mcp/.env`) |
| `DISCORD_PROACTIVE_ENTRYPOINT` | `index.mjs`, `controller.mjs` | Daemon script (the plugin points it at `runtime/proactive.cjs`) |
| `DISCORD_CODEX_COMMAND` / `CODEX_CLI_PATH` | `controller.mjs`, `conversation.mjs` | Codex CLI executable (otherwise `codex`, `~/.local/bin/codex`, or the macOS ChatGPT app bundle) |
| `XDG_CONFIG_HOME` / `XDG_DATA_HOME` | `nova-settings.mjs`, `state.mjs`, plugin | Base directories (defaults `~/.config`, `~/.local/share`) |

Accounts are sorted by `priority` (desc), then by `id`. Routing prefers accounts
that discovery saw in a guild.

## Model defaults

`src/proactive/reply-defaults.mjs` holds the default `model`,
`reasoningEffort: 'low'` and `serviceTier: 'priority'` (Fast). Per-conversation
overrides persist in `nova.json`.

## Files on disk

`$DATA` = `$XDG_DATA_HOME/discord-mcp` (default `~/.local/share/discord-mcp`).
`$CONF` = `$XDG_CONFIG_HOME/discord-mcp` (default `~/.config/discord-mcp`).

| Path | Owner module | Contents |
| --- | --- | --- |
| `$CONF/.env` | plugin `start.mjs` | Tokens and account env (user-managed) |
| `$CONF/nova.json` | `nova-settings.mjs` | `projectRoots`, `voice`, `conversations["<account>:<channel>"]` overrides (model, effort, tier, timeouts, paused), `web` / `media` / `playbooks` toggles |
| `$DATA/proactive/<account>-<channel>.json` | `controller.mjs`, `daemon.mjs` | Listener configuration: `listenerId`, `controlToken`, `controlUrl`, `pid`, mode, model, pacing (0600) |
| `$DATA/proactive/<account>-dm-<owner>.json` / `<account>-servers.json` | same | DM / all-servers listener configuration |
| `…/<target>.status.json` | `daemon.mjs` (via `state-writer`), `supervisor.mjs` | Live status snapshot and statistics |
| `…/<target>.json.supervision.json` | `controller.mjs`, `supervisor.mjs` | `{enabled, pid}`. Disable this to stop restarts |
| `…/<target>.log` | daemon stdout and stderr | Listener log |
| `…/<target>.json.starting`, `$DATA/proactive/<account>-servers.starting` | `controller.mjs` | Start locks (stale locks are reclaimed if the PID is gone) |
| `$DATA/proactive/research-jobs/<account>-<id>.json` | `research-jobs.mjs` | Research job records |
| `$DATA/memory/<account>-<channel or dm-owner>/memory.md` | `memory.mjs` | Owner-approved memory |
| `$DATA/delivery/<account>-<channel>.json` | `delivery-journal.mjs` | Ingress claims, send operations and receipts (7-day retention, ≤ 2000 entries). **Hard-coded to `~/.local/share`** (ignores `XDG_DATA_HOME`) |
| `$DATA/digests/…` | `digests.mjs` | Digest schedules and cursors. Also hard-coded under `~/.local/share` |

See `state.mjs` (`listenerTargetPaths`) for exact naming.
